# 문제 기록부 (lessons)

> **읽는 시점**: 검사가 실패했거나, 사용자가 실수를 지적했거나, 리뷰에서 문제가 나왔을 때. 평소 작업에서는 읽지 않습니다.

## 절차: 기록 → 장치화 → 재현 테스트
1. **기록**: 아래 목록에 항목을 추가합니다. 번호는 `L-NN`으로 이어서 매기고, 증상·원인·조치·장치를 적습니다.
2. **장치화**: 같은 문제가 다시 들어오지 못하게 막습니다. 가능한 것부터 적용합니다.
   - 결과물에서 잡을 수 있음 → `tools/checks/`에 규칙 추가(`origin`에 L 번호)
   - 작업 과정에서 막아야 함 → `tools/hooks/` (판단은 `decide.py` 한 곳에서)
   - 기계로 못 잡음 → 해당 guide에 한 줄
3. **재현 테스트**: 문제를 일부러 다시 만들어 장치가 잡는지 확인합니다. 검사 규칙이면 `tools/test_checks.py`에 mutation을 추가합니다.

- **단계적 강화**: 처음 발생하면 기록(+가능하면 장치)하고, 같은 문제가 재발하면 반드시 스크립트나 hook으로 올립니다.
- **권한**: 이 파일의 기록과 검사 규칙 추가는 Claude가 바로 합니다. guide와 `CLAUDE.md` 수정은 사용자 확인을 받습니다.
